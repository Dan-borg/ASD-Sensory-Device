# ASD-Sensory-Device

## ASD Sensory Feedback Device

A low-cost adaptive sensory feedback device built with ESP32 and Arduino 
for supporting self-regulation in children aged 3-7 with Autism Spectrum Disorder.

## Research
Bachelor of Science in Software Development — MCAST Malta
Academic Year 2025/2026

## Device
- ESP32 microcontroller
- FSR pressure sensor
- Vibration motor (PWM controlled)
- Colour-coded LEDs

## Research Questions
- RQ1: Do adaptive sensory feedback devices improve self-regulation in ASD children?
- RQ2: How accurately can low-cost sensors detect interaction patterns?
- RQ3: Does real-time cause-and-effect feedback support engagement in children aged 3-7?
